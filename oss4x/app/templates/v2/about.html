An open-source search engine for open-source code in the {{ APPLICATION_FIELD }} field

This is a search engine for open-source code in the {{ APPLICATION_FIELD }} sector, and the project itself is fully open-source.

As far as we know, this project is currently unique in combining the following aspects:

  • it is 100% open-source (including the underlying data),
  • it references repositories across hosting platforms,
  • it has a high repository coverage, as it combines data from the largest open-source indexes in the field,
  • it is self-maintaining (i.e., the underlying data is regularly updated automatically to prevent dead links).

Data sources and credits

The underlying dataset is built from open listings contributed by communities and individuals. They are credited on the search page {% if URL_LISTINGS_INDEX %} and in the listings index {% endif %} — thank you to all of them for their work!

Contribution and feedback

The project is open-source and welcomes contributions of all kinds: you can check its code repository, provide quick feedback, or get in touch with the maintainer here.

Indexing and scraping methodology

The indexing and scraping methodology is fully transparent on the code repository. It is nevertheless worth knowing that:

  • indexing for search is only based upon descriptions and readme files of the repositories (this is quite restrictive),
  • search is keyword-based for now (e.g. adjacent terms are not considered at this stage).
